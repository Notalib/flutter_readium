**Android: opening a streamed Web Publication no longer fetches every chapter up front.**
The EPUB positions service probed each reading-order resource over HTTP, so opening the player issued a request — at minimum a HEAD, and on some containers a full download — per chapter before first paint. Streamed (HTTP-backed) EPUB-profile publications now compute one position per chapter without any network; local zip EPUBs keep byte-granular positions. Per-chapter injection no longer costs an extra HEAD either. Progress-bar granularity for streamed publications is coarser: one step per chapter.
