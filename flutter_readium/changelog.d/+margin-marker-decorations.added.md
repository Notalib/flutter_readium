**Margin marker decorations.**
`DecorationStyle.marginMarker` shows a text label or a built-in icon (bookmark, note or star) in the margin, level with the first line of a locator, on iOS, Android and web.
By default a marker sits a small gap from the text column; `anchor: MarginAnchor.page` puts it at the page edge instead. Use it for printed page numbers or bookmarked highlights. See the [margin markers guide](https://github.com/Notalib/flutter_readium/blob/main/docs/guides/margin-markers.md).
