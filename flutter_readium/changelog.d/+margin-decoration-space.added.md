**Room for margin markers at any font size.**
At large font sizes a margin marker could overlap the text, because the page margin does not grow with the font.
The opt-in `EPUBPreferences.makeSpaceForMarginDecoration` widens the side margins with the font size so markers fit, on iOS, Android and web. See the [margin markers guide](https://github.com/Notalib/flutter_readium/blob/main/docs/guides/margin-markers.md#margin-width).
